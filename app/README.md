# Турия — миниапп

Telegram Mini App: дневник внимания, юнгианское толкование и интерактивные истории.
Что и зачем — в [`../docs/CONCEPT.md`](../docs/CONCEPT.md). Как устроено внутри — в [`../docs/ENGINE.md`](../docs/ENGINE.md). План и роли — в [`../docs/ROADMAP.md`](../docs/ROADMAP.md).

## Запуск

```bash
npm install
cp .env.example .env   # заполнить ключами Supabase
npm run dev
```

Приложение запускается и вне Telegram: если `initData` пустой, вместо главной кнопки мессенджера
показывается обычная кнопка. Это нужно, чтобы разрабатывать в браузере.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run build` | типы плюс продакшн-сборка в `dist/` |
| `npm run lint` | линтер |
| `npm run preview` | предпросмотр собранного |

## Структура

```
src/
├── screens/     экраны петли: улов, паттерны, чтение, разбор, сонник
├── components/  общие блоки
├── lib/         telegram.ts — обёртка над WebApp, supabase.ts — клиент
├── store/       состояние сессии и черновик улова
├── types/       доменные типы — зеркало docs/ENGINE.md §6
└── styles/      дизайн-токены
```

`src/types/domain.ts` повторяет спецификацию из `docs/ENGINE.md`. Расхождение между ними
считается багом в коде, а не в документе.
